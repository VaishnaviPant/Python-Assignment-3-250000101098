## Topics Covered in Detail

The 50 programs are organized around the following Python programming concepts:

1. **String Basics** – Creating strings, accepting input and finding string length.
2. **String Manipulation** – Reversing strings, checking palindromes, replacing spaces and changing letter cases.
3. **Character Operations** – Counting vowels, consonants, uppercase characters, lowercase characters, digits and special characters.
4. **String Methods** – Using count(), find(), rfind(), startswith(), endswith(), strip(), replace(), split() and join().
5. **String Formatting** – Using format() and f-strings.
6. **String Operations** – Escape characters, raw strings, quotation marks, concatenation and repetition.
7. **List Basics** – Creating lists, accessing elements and performing indexing operations.
8. **List Operations** – Inserting, appending, removing, deleting, sorting and reversing elements.
9. **List Processing** – Finding maximum and minimum values, calculating sum and average, and counting even and odd elements.
10. **List Manipulation** – Removing duplicates, merging lists, finding common elements, slicing and copying lists.
11. **List Methods** – Using append(), extend(), insert(), remove(), pop(), reverse(), sort() and copy().
12. **Tuple Operations** – Creating tuples, indexing, counting occurrences, concatenation, repetition and slicing.
13. **Tuple Immutability** – Understanding immutable sequences and creating modified tuples using concatenation.
14. **Set Operations** – Performing union, intersection, difference and symmetric difference.

## Execution Instructions

### Prerequisites

- **Python Version:** Python 3.8 or higher
- **Editor:** Visual Studio Code (VS Code)
- **Dependencies:** No external libraries are required. All programs use the Python standard library.

### Run a Program

Open a terminal in the repository folder and execute an individual Python file:

```bash
python Q01.py
```

On systems where Python 3 is invoked separately, use:

```bash
python3 Q01.py
```

Replace `Q01.py` with the desired question number to execute another program.

Programs that require user input will prompt for the necessary values in the terminal.
